# ☕ Coffee Sales Dashboard

## 📌 Project Overview

The Coffee Sales Dashboard is a data analysis project that transforms raw coffee sales data into meaningful insights through data visualization.

The project focuses on analyzing sales trends, comparing sales across countries, and identifying the top-performing customers.

## 🎯 Project Objectives

* Analyze coffee sales data.
* Track sales trends over time.
* Compare sales performance across countries.
* Identify the top 5 customers by sales value.
* Explore sales using different filters.

## 📊 Dashboard Features

### 1. Total Sales Over Time

A line chart that shows sales trends over time and compares different coffee types.

### 2. Sales by Country

A horizontal bar chart that compares sales across countries.

### 3. Top 5 Customers

A chart highlighting the five customers with the highest sales values.

### 4. Interactive Filters

The dashboard includes filters for:

* Order Date
* Roast Type
* Coffee Size
* Loyalty Card Status
